# RBA Kids — результаты и турнирные таблицы

Статический сайт с результатами и турнирными таблицами чемпионата **RBA Kids**
(Rostov Basketball Association, Ростов-на-Дону) за сезоны **2024/25 — 2026/27**.

**Источник данных:** карточки матчей VK-сообщества [Rostov Basketball Association | RBA](https://vk.com/rba_rostov_basketball).

## Сайт
- **Таблицы** — турнирные таблицы по сезонам и возрастным группам; сортировка по колонкам; подсветка «моей команды»; итоги сезонов (чемпионы/призёры)
- **Матчи** — все результаты с фильтрами: сезон, группа, команда, месяц, площадка
- **Команды** — статистика команды за все сезоны, head-to-head с соперниками, все матчи

Сайт работает без сборщиков и серверной логики: `index.html` + `styles.css` + `app.js` + `data.js`.
GitHub Pages отдаёт корень репозитория как есть.

## Структура
```
index.html, styles.css, app.js   — сайт
data.js                          — данные для сайта (генерится скриптами)
scripts/                         — пайплайн обновления данных
data/                            — состояние и артефакты (посты, транскрипции, датасеты)
img/, pages/                     — локальные картинки и кэш ВК (в git не хранятся)
```

## Обновление данных
```
./scripts/update.sh            # всё: сбор новых игр -> распознавание -> сборка -> git commit
./scripts/update.sh --push     # то же + push (GitHub Pages обновится)
./scripts/update.sh status     # что нового / сколько не обработано
./scripts/update.sh build      # только пересобрать данные и data.js
```

Пайплайн: новые посты ВК → карточки матчей (картинки) → распознавание (pi-агенты,
батчами) → пересчёт таблиц → `data.js` → commit. Обрабатываются только новые
посты и картинки — повторные запуски быстрые.

Если нужен прокси для доступа к VK:
```
HTTPS_PROXY=https://user:pass@host:port ./scripts/update.sh
```
Модель распознавания: `PI_PROVIDER=... PI_MODEL=... ./scripts/update.sh`

## Данные
- `data/games.json` — все распознанные матчи
- `data/rba_kids_dataset.json` — полный датасет (матчи, таблицы, официальные итоги)
- `data/out/*.txt` — транскрипции карточек (первоисточник распознавания)
- `data/report.md` — человекочитаемый отчёт

Очки: 2 за победу, 1 за поражение. Таблицы рассчитываются автоматически по
результатам карточек матчей; официальные итоги (финалы, призёры) — из публикаций RBA.
