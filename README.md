# RBA Kids — результаты и турнирные таблицы

Статический сайт с результатами и турнирными таблицами чемпионата RBA Kids
(Rostov Basketball Association, Ростов-на-Дону) за сезоны 2024/25 — 2026/27.

**Источник данных:** карточки матчей VK-сообщества [Rostov Basketball Association | RBA](https://vk.com/rba_rostov_basketball).

## Что на сайте
- **Таблицы** — турнирные таблицы по сезонам и возрастным группам, сортировка по колонкам, выбор «моей команды» (подсветка), итоги сезонов (чемпионы/призёры)
- **Матчи** — все результаты с фильтрами: сезон, группа, команда, месяц, площадка
- **Команды** — статистика команды за все сезоны, история матчей с соперниками (head-to-head)

## Структура
- `index.html`, `styles.css`, `app.js` — сайт (vanilla JS, без сборщиков)
- `data.js` — все данные (201 матч, таблицы, официальные итоги)

## Обновление данных
1. Пересобрать данные: `python3 build_dataset.py` (из папки проекта)
2. Сгенерировать `data.js` из `rba_kids_dataset.json`
3. Закоммитить и запушить — GitHub Pages обновится автоматически

Очки: 2 за победу, 1 за поражение.
